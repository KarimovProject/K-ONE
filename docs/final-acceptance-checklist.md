# IEMS final staff acceptance checklist

Use a test event and test accounts. Mark each item Pass, Fail or Not applicable. Never use real social credentials during this walkthrough.

1. Open the login page, enter a valid account and confirm the dashboard opens. Confirm an invalid password does not log in.
2. Open Master Data. Review a venue, event type, organization and sponsor. With an administrator account, create or update one test record.
3. Create a test event through all wizard steps. Confirm required-field messages are understandable.
4. Choose an occupied venue/time and confirm the conflict warning appears. Return to an available time.
5. Save the event and submit it for approval. Confirm the status changes.
6. With a management account, approve one test event and reject another with a reason.
7. Exercise the emergency override using test events. Confirm the displaced event is visible and can be rescheduled.
8. Add a manual agenda item. Upload a small valid PDF and confirm invalid/non-PDF content is rejected.
9. Open the QR page, rotate the test token and confirm the old link stops working.
10. Open the public event page in a private browser. Confirm no staff notes, emails or internal approval information appear.
11. Enable the check-in window and submit a public check-in. Double-click and confirm the attendee count increases only once.
12. Open Attendance as reception staff, add one manual attendee and download the authorized CSV.
13. Open the Leadership dashboard. Confirm venue state, today's events and upcoming events are plausible.
14. Open a tokenized TV wallboard. Disable/rotate the display token and confirm the old URL is rejected.
15. Open Telegram settings. Confirm the disabled/unconfigured state is honest. Do not claim live reminders without credentials.
16. Create a publication draft, generate a banner and preview platform-specific text. Use fake transports only.
17. Open Reports, apply filters and download CSV/XLSX/PDF. Confirm reception sees attendance only and content staff publications only.
18. Switch between UZ, RU and EN on key pages. Confirm labels and errors do not mix languages.
19. Repeat login, public event, check-in, publication composer and reports on a phone-sized viewport.
20. Navigate with keyboard, confirm focus remains visible, then log out. Confirm protected pages redirect to login and the browser Back button does not restore access.

Record browser, device, account role, date, failed step, screenshot and exact message for every failure.
